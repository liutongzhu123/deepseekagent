# 3 类报告样例模板（合成示例，不含客户数据）

> **用途**：对齐三类报告的字段、页结构、期望审核输出和验收记录格式。
> **重要**：本文件所有编号、单位、日期、评分均为**合成示例**，不是客户报告，不能作为阶段 3 验收样本。真实样本来自 D1/D3，且只放工单本地目录。

## 1. A 类 · 比亚迪气味 OTS 报告（5 页）

### 1.1 字段模板

| 字段 | 示例值（合成） | 说明 |
|---|---|---|
| 报告编号 | `S3-OTS-001` | 封面与页眉应一致 |
| 样品编号 | `S3-SAMPLE-001` | 与任务单/样品清单可对应（D4） |
| 委托单位 | `示例委托单位` | 不写真实客户名 |
| 样品名称 | `示例样品` | 与样品情况表一致 |
| 样品数量 | `3 件` | 与摘要/样品表一致 |
| 检验项目 | `气味` | BYD-odor 识别条件之一 |
| 检验依据 | `Q/BYDQ-A1901.404—2025` | BYD-odor 识别条件之一 |
| 检验开始日期 | `2026-01-05` | 早于结束日期 |
| 检验结束日期 | `2026-01-07` | 早于批准日期 |
| 符合性判定 | `符合` | 与均值/限值一致 |
| 设备溯源有效期 | `2026-12-31` | 选填；有 D4 时核对 |

### 1.2 页结构核对（以客户真实模板为准）

| 页 | 内容（示例结构） | 验收关注点 |
|---|---|---|
| P1 | 封面 | 报告编号、样品编号、委托单位、判定 |
| P2 | 摘要/样品信息 | R03 字段一致性 |
| P3 | 检验结果/评分 | 3 名评价员评分、均值、限值、R02 |
| P4 | 结论/签名 | R06、R10 签名/印章 |
| P5 | 注意事项/附页 | R08 注意事项条数、R07 页码 |

> 当前代码只用**总页数 5** 区分 OTS 变体，不依赖上述页序；真实模板页序不同不改变 A 类判定，但金标准须记录实际页序。

### 1.3 合成示例与期望输出

示例假设：5 页、BYD-odor/OTS、评分 3.0/3.0/3.0、均值 3.0、限值 3.5、判定“符合”、日期顺序正确、注意事项 8 条、有嵌入签名/印章、无高亮/红字。

| 规则 | 期望 | 说明 |
|---|---|---|
| R01 | pass | 封面与正文编号一致 |
| R02 | pass | 均值 3.0 正确 |
| R03 | pass | 摘要与样品表一致 |
| R04 | pass | 日期顺序正确 |
| R05 | pass/skip | 有设备有效期则核对，无则 skip 并注明 |
| R06 | pass | 判定与均值/限值一致 |
| R07 | pass | 共 5 页、页码连续 |
| R08 | pass | 注意事项 8 条 |
| R09 | pass | 无高亮/红字 |
| R10 | pass | 签名/印章图片已嵌入 |
| R11 | pass | 识别为 BYD-odor（OTS） |
| P01 | skip（无 D4） | 任务单未提供 |
| P02 | pass | 目录页码在范围内 |
| P03 | pass | 单项检验时间在汇总时间内 |
| P04 | skip（无 D4） | 无结构化单位列 |
| P05 | skip（无 D4） | 无平行样编号 |
| P06 | skip（视觉未接入） | 显示“未自动审核” |
| P07 | pass | 无高亮/红字 |
| P08 | skip | 当前仅覆盖 BYD |
| DSL | 按报告字段执行 | D06 仅“不符合”时命中；D09 无输入则 skip |
| SEM | 未检查（D5 未确认） | 不得 pass |

> 期望输出是模板示意；实际以 `audit_report(..., stage2=True)` 运行结果与客户金标准为准。

### 1.4 缺陷示例（用于验证检出）

| 缺陷 | 期望结果 |
|---|---|
| 页眉报告编号空白 | R01 fail |
| 均值单元格空白（有 3 个评分） | R02 fail（报告均值缺失） |
| 判定“符合”但均值超限 | R06 fail |
| 含黄色高亮/红字 | R09 fail、P07 fail |
| 无嵌入签名/印章图片 | R10 fail |
| 总页数为 4 而不是 5 | R11 按摸底/未识别返回，模板分类失败（不得算 A 类通过） |

## 2. B 类 · 比亚迪气味摸底报告（4 页）

### 2.1 字段模板

字段与 A 类相同（见 1.1）。合成示例编号用 `S3-MOBAN-001`，其余字段同 A 类。

### 2.2 页结构核对（以客户真实模板为准）

| 页 | 内容（示例结构） | 验收关注点 |
|---|---|---|
| P1 | 封面 | 报告编号、样品编号、委托单位、判定 |
| P2 | 摘要/样品信息 | R03 |
| P3 | 检验结果/评分 | R02 |
| P4 | 结论/签名/注意事项 | R06、R08、R10、R07 |

> 当前代码只用**总页数 4** 区分摸底变体；实际页序以客户模板为准。

### 2.3 合成示例与期望输出

与 A 类 1.3 相同，差异仅在：

- R07 期望“共 4 页、页码连续”；
- R11 期望识别为 `BYD-odor（摸底）`，不得识别成 OTS；
- 若客户摸底模板的注意事项条数不是 8，R08 以金标准标注为准。

### 2.4 缺陷示例

| 缺陷 | 期望结果 |
|---|---|
| 页眉编号与封面不一致 | R01 fail |
| 模板被识别为 OTS（页数误判） | R11 与本类金标准不符，模板分类失败 |
| 均值小数位/计算错误 | R02 fail |
| 时间顺序错误 | R04 fail |

## 3. C 类 · XG 变更报告（待 D1，占位模板）

> **状态：blocked（D1）**。当前无样例、无 `xg_change.yaml`、无字段映射；R11 对未知模板返回 `warn`，不是 `pass`。以下字段为**待确认骨架**，D1 到位后由客户业务确认，不能直接当验收标准。

### 3.2 D1 到位后要补的验收标准

1. 新增 C 类模板配置与字段映射，`identify_template` 可识别 C 类，R11 `pass`。
2. 2–3 份 D1 样例做模板回归：C 类识别 100%，不与 A/B 误判。
3. D3 的 C 类正式报告按 A 类同一套指标验收（报告级准确率 ≥95%、finding 召回 ≥90%、R01/R04/R06 100%、≤60s、干净报告 0 误报）。
4. 变更前后内容一致性、原报告号可追溯作为附加检查，具体规则/阈值由客户确认。
5. 上述未完成前，C 类不得计入“3 类通过”。

## 4. 使用方式

1. 复制本文件的对应类模板到 `templates/acceptance-record.md` 的单份记录中。
2. 用真实样本的**假号**替换示例编号；不要写真实报告编号/VIN/联系人。
3. 金标准由客户业务专家填写；agent 只填实际运行结果与指标。
4. 合成示例只用于对齐格式；验收统计只使用 D1/D3 真实样本。
