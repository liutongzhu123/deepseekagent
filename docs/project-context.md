# 项目背景与交付约束（agent 必读）

> 记录时间：2026-11-07。**每轮开工前先读这一页**，避免重复追问已经定过的事。

## 一、阶段

**开发测试期**，不是正式交付期。项目尚未招投标，合同未签；当前是测试环境，没有生产环境。

## 二、模型策略

| 阶段 | 模型来源 |
|---|---|
| 现在（测试期） | 公网 DeepSeek API |
| 未来（客户侧部署） | **全部本地模型，硬件和模型由客户提供** |

推论：
1. 现在不做模型本地化（T402 已实测：CPU 5.5 tok/s、图像 62s/张，不可用，归档 `verified-deferred`）
2. 客户侧部署时 GPU 由客户负责，我方只提供部署方案和模型接入配置
3. 代码必须保持模型可切换（`P0_SEMANTIC_BASE_URL` / `P0_SEMANTIC_MODEL` 已支持）
4. rerank 当前 CPU 不可用（P95 54.6s），等客户 GPU 或 WeKnora 支持可配候选池后重测

## 三、数据策略

客户因招投标未完成，**暂时无法提供** D1–D6（见 PLAN 第五节）。

**当前做法：用模拟数据推进，不等客户。**

可用替代数据：12 份比亚迪草稿（同编号模板变体）、4 条真实记录 + 16 变异、44 条合成语义用例、1 份带水印标准。

约定：
1. 模拟数据必须在文档里标明口径，不能当客户金标准
2. **不能因为缺数据停工**；缺数据的任务标 `blocked` 跳过，继续做别的
3. 招投标完成后由客户提供真实数据，届时用真实数据复测全部指标
4. 现在的准确率/召回都是**基线**，不是验收结论

## 四、给 agent 的硬约束

1. **不要反复索要 D1–D6**：已在等客户，问一次记录即可
2. 缺数据的任务标 `blocked` 并跳过，不要停下来空等
3. 所有结论必须标注数据口径（模拟/真实、样本量、环境）
4. 测试期指标只能叫"基线"，不能叫"验收通过"
