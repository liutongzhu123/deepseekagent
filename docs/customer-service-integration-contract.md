## 2. 适配层统一结果约定（设计建议，待客户安全评审）

适配器只返回脱敏的规范化结果，不把供应商原始响应、凭据、完整客户资料或本机路径写入普通日志。每次外部动作应保留内部 `operation_id`、适配器名称、动作类型、结果分类、时间、可安全记录的外部请求/记录标识及幂等键摘要。

建议结果分类：

| 分类 | 含义 | 业务处理 |
|---|---|---|
| `succeeded` | 已收到并校验必需字段的成功回执 | 只有业务状态机确认该回执含义后才推进状态 |
| `pending` | 已受理但尚无最终回执 | 保留待办/轮询任务，不标记最终成功 |
| `retryable_failure` | 超时、临时不可用或限流 | 仅对已批准的安全动作按退避和配额策略重试；保持原业务状态 |
| `permanent_failure` | 认证/授权失败、明确拒绝或无效请求 | 停止自动重试，通知运维/人工处理 |
| `schema_changed` | 必需字段缺失、类型变化或无法解释的状态值 | 隔离响应，保留脱敏诊断，转人工；不猜字段、不丢字段后继续 |
| `duplicate_or_conflict` | 幂等键已存在但请求不一致，或远端状态冲突 | 不重复副作用；对账后人工处置 |

## 3. 故障与并发验收矩阵

每种情景必须针对 CRM、企查查、微信/企微、邮件分别运行。字段变化用客户批准的真实契约样例；客户样例到位前，只能验证规范化适配器对必需字段缺失的闭锁行为，不能声称供应商字段兼容性已验收。

| 编号 | 情景 | 预期适配层行为 | 预期业务状态 | 证据/当前状态 |
|---|---|---|---|---|
| F1 | 正常成功回执 | 校验必需字段与来源标识；不记录凭据/原始 PII | 由对应状态机按明确回执推进 | CRM 文件适配有本地测试；规范化合成回执已验证；四类生产 API 待实现 |
| F2 | 连接/读取/写入超时 | 分类为临时失败；调用方可重试时需有边界与退避 | 注册/报价/委托不默认放行或完成；消息保留待办 | 本地超时分类及同键重试已验证；真实调用未实现 |
| F3 | 认证失败/权限不足 | 分类为永久配置错误，不无限重试 | 原状态不变，进入运维/人工队列 | 合成认证失败分类已验证；真实凭据与权限仍待客户 |
| F4 | 速率限制 | 读取 `Retry-After` 或供应商限流字段；按获批上限延迟重试 | 不重复创建报价、委托、消息或注册 | 本地固定上限延迟分类已验证；供应商限流口径待确认 |
| F5 | 同一请求重复提交 | 写操作使用稳定幂等键；同键同载荷返回同一结果，同键异载荷冲突；读操作可安全重试 | 不产生重复外部副作用 | 客服本地 JSON 演示已支持同键稳定重放/冲突及 POSIX 多进程锁；生产持久化幂等仍须数据库事务/唯一约束，集成模拟器仍为进程内 |
| F6 | 必需字段新增/缺失/类型改变或未知状态 | 不静默丢弃必需字段；标记 `schema_changed` 并隔离 | 转人工，不自动改变业务判定 | 本地合成 schema-change 分类已验证；供应商 schema 与样例待提供 |
| F7 | 超时后远端已成功但本地无回执 | 先按幂等键/外部请求号查询或对账，不盲目重发 | 保持 `pending`，直到回读确认或人工核对 | 本地模拟保持 pending，只有显式 read-back 才报告回执；生产回读契约待提供 |

本地 `IntegrationSimulator`（`p0/app/integration_simulator.py`）可在测试中合成上述 F1–F7 的规范化结果，幂等状态只驻留内存，索引键使用系统/动作/进程密钥 HMAC；审计仅留操作编号、白名单系统/动作、结果类型和 HMAC，不在实例中保留原始调用 key、payload 或凭据。它没有网络客户端、未挂接业务路由，也不会把合成回执写入客户注册/报价/委托；测试通过只证明应用层对这些分类的解释，不证明供应商兼容、远端幂等或生产副作用安全。

## 4. 按系统的接入顺序与安全约束

1. **CRM 先只读：** 先确认项目唯一映射、价格/排期/资质的字段及版本语义；接入后继续复用项目级权限过滤。写入/同步排最后，必须单独审批并有幂等、预览、对账和回滚。
2. **企查查只提供风险事实：** 企业匹配不确定、超时、授权错误、黑白名单冲突均走人工审核；不得将服务商分值直接当成自动拒绝结论。
3. **微信/企微先验身份与回调：** 服务端验证平台签名和客户授权；不能信任客户端自报企业、身份或消息发送状态。出站失败保留内部待办，客户状态不得假报已送达。
4. **邮件最后接确认：** 邮件已发送、已送达、客户已确认是三个状态；用回执/链接令牌绑定具体委托版本。退信和超时不等于客户拒绝或确认。
5. **每个系统独立开关：** 未配置、配置不完整、错误环境或字段校验失败时均 fail closed；绝不回退到合成数据并展示成生产结果。
