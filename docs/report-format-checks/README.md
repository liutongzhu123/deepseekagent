# 报告审核 · 格式与完整性检查（阶段 A）

> 对应客户《AI 报告审核功能要求》中「格式与完整性」类检查。全部不依赖客户业务数据，
> 基于 docx 结构/文本/样式确定性判定；每项一个独立 PR、独立单测，规则号续在 `R11` 之后。
> 12 份真实草稿已挂载在 `/opt/dsh-agent/samples/byd`；T510 已用其中 12 份回归，结果见文末。

## A1 · 空白页 / 窜页 / 乱码（R12）

**检查什么**

- 空白页：按分页符切页，页级去空白字符数 ≤2 且无图片。
- 窜页：页脚页码断档、重复或乱序。
- 乱码：U+FFFD、Unicode 控制/私有区字符，以及 `锟斤拷`/`ï¿½`/`â€` 等常见乱码串。

**怎么判定**

- 任一子项命中即 `fail`；空白页、页码断档/重复为高严重级别，个别乱码为中。
- 无页码或无法按分页符分段时返回 `skip` 并写明原因，不冒充 `pass`。
- 定位：空白页给页码，断档给缺失页码，乱码给页级/全文。

**已知局限**

- docx 无固定版面，分页依赖 `w:br type="page"` / `w:lastRenderedPageBreak`；
  无分页标记的文档只能查页脚断档，不能判空白页。
- 页眉/页脚图片不计入正文图片覆盖率；纯图片页按“有图”处理。
- 与 `R07` 有交叠：`R07` 校验「共 N 页 + 1..N 连续」，`R12` 另报断档/重复/乱序、空白页与乱码。

## A2 · 书签完整性（R13）

**检查什么**

- 书签开始/结束是否配对：`w:bookmarkStart` 没有对应 `w:bookmarkEnd`。
- 书签是否重名：同一书签名出现多次。
- 内部引用是否失效：目录超链接 `w:hyperlink w:anchor`、`REF/PAGEREF` 域指向不存在的书签。
- 忽略 Word 内部 `_GoBack` 书签；正常 `_Toc` 书签照常检查。
- `w:bookmarkEnd` 可能出现在段落之外（如 OLE 对象周围），解析器已改为全文档收集。

**怎么判定**

- 存在失效引用、未闭合书签或重名 → `fail`；失效引用为高严重级别。
- 问题信息带书签名与段落序号；定位栏写“书签/目录”。
- 报告没有书签、也没有内部引用时返回 `skip`，不冒充 `pass`。

**已知局限**

- 只检查 docx 内部书签与引用，不判断目录页码是否与正文一致（见 `R07`/`R18`）。
- 书签位置用 XML 段落序号，不是渲染页码；跨页/表格内段落序号可能与 Word 页码不一致。
- 复杂域（嵌套域、`w:instrText` 分片）只做字符串级 `REF/PAGEREF` 提取，极端域结构可能漏报。

## A3 · 空缺项未填写也未杠掉（R14）

**检查什么**

- 表格必填项标签（如样品编号、委托单位、检验依据、设备编号、溯源有效期等）右侧/下方的值单元格。
- 表头型必填列：表头命中必填项时，检查该列数据行。
- 单元格空值、纯下划线/`XX`/`待填` 等占位符；`/`、`—`、`不适用`、`N/A` 视为明确杠掉。

**怎么判定**

- 必填项为空 → “未填写”；仍保留 `___`/`XX` 等占位符 → “占位符未替换”；两者均 `fail`。
- 明确杠掉计入“合理留空”，不报；非必填标签（如备注）不扫描。
- 无表格或未识别到必填项标签时 `skip` 并注明；问题信息带表号、行号与标签。

**已知局限**

- 必填项清单是内置默认值（`p0/app/format_rules.py` 的 `_REQUIRED_LABELS`），未接客户字段配置；
  不同模板的必填标签可能漏检或误检。
- 只做标签邻接/表头列检查，不推断合并单元格的业务含义；整行空白是模板排版时可能被报。
- 不检查表外正文的空缺项（如“见附页”）。

## A4 · 章节 / 项目编号跳号（R15）

**检查什么**

- 多级章节号（`5.1`、`5.2`…）：按父级分组，子号应从 1 连续；检测断档与重复。
- 单级编号（`1.`、`2.`…）与括号编号（`（1）`、`（2）`…）：按出现顺序检测断档/重复，遇到回到 1 视为新序列。
- 自动排除“3.5 符合”“10.2 mg/m³”这类测量/判定文本，避免把数值误当章节号。

**怎么判定**

- 编号断档、重复 → `fail`（中严重级别），信息带编号与段落序号。
- 未识别到任何章节/项目编号时 `skip`，不冒充 `pass`。
- 断档判定按序列进行：`1→3` 报“断档”，`3→1` 视为新列表不报。

**已知局限**

- 依赖文本行首编号，不解析 Word 多级列表/自动编号；自动编号文档可能识别不到。
- 短标题（≤40 字）才纳入，长标题或编号后直接接正文的模板可能漏检。
- 多个并列列表都从 1 开始时，按“回到 1 = 新序列”处理，不能识别跨列表的重复编号。

## A5 · 计量单位规范（R16）

**检查什么**

- 数值后的单位 token（`100 MPa`、`25 ℃`、`5 N·m`、`10 mm` 等）。
- 白名单内单位的大小写：`mpa`/`kpa`/`Mpa`/`KN`/`n·m`/`°c` 等报错，给出应写形式。
- 单字母单位（`m`/`g`/`L`/`s`）与 `%`、`‰` 暂不做大小写判定，避免与变量/编号混淆。

**怎么判定**

- 单位 lower 命中白名单但原写法不等于规范写法 → `fail`，信息带段落序号与“错误→应写”。
- 未识别到数值后单位时 `skip`；白名单外单位（如 `bar`）不误报，也不代表已审核。

**已知局限**

- 白名单内置在 `p0/app/format_rules.py`，未接客户单位字典；新单位需改代码/后续配置化。
- 只查大小写，不查单位与物理量的匹配（如压力写成 `mm`）、中英文单位混用或上下标缺失。
- 依赖“数字后紧跟单位”的文本形态；表格中单位单独占一列时不会关联到数值。

## A6 · 字体字号一致（R17）

**检查什么**

- 段落级显式字体（`w:rFonts` 的 eastAsia/ascii/hAnsi）与字号（`w:sz`）。
- 以正文段落（≥20 字、非加粗、非编号标题）的众数为“正文主体”，找出字体或字号偏离的段落。
- 报出段落序号、片段、字体名、字号，并与主体样式对比。

**怎么判定**

- 偏离段落存在 → `warn`（中严重级别），提示人工确认是否为刻意强调。
- 正文样本 <5 段 → `skip`，不冒充 `pass`。
- 标题（短、编号开头）与加粗段落不纳入统计。
- 封面、目录（省略号/点线引导线）与“注/备注/说明”小字号说明段落不纳入偏离统计。

**已知局限**

- 只统计显式设置的字体/字号；继承样式或主题字体在 XML 中没有显式值时无法判定。
- 众数法假设正文占多数；正文本身混排多种字体，或模板正文比例低时可能误报/漏报。
- 不比较字间距、行距、颜色、下划线等其它排版属性。

## A7 · 注意事项必填项（R08 扩展）

**检查什么**

- 原条数口径（中文报告默认 8 条，管理员可配）由 R08 保留；逐条固定文本核对见 A17（R28）。
- 注意事项页的「委托单位」必填、「试验类型」必选。
- 注意事项页内的值优先；没有时回退到报告摘要的委托单位与模板变体（BYD 的 OTS/摸底）。

**怎么判定**

- 条数不符、委托单位空/占位、试验类型空/占位 → 合并为一个 `R08` finding；信息列出全部问题。
- 未识别到注意事项段落时 `skip`，不冒充 `pass`；管理员把条数阈值配成 0 时整条规则 `skip`。
- `_notice_value` 只匹配行首的标签（允许 `1.` 前缀），避免把正文里提到“委托单位”的句子误当字段值。

**已知局限**

- 字段值提取是行首标签 + 下一行回退，复杂表格布局（标签与值不在同一行/相邻行）可能漏检。
- BYD 以外模板的“试验类型”回退到检验项目；没有统一枚举，无法判断类型是否选错。
- 注意事项页不存在时无法检查必填项，只能 `skip`。


## A8 · XG 编号规则（预留，配置化不判定）

**检查什么**

- 本项**不实现判定逻辑**。只把客户待确认的规则做成配置：
  - `enabled`：总开关，默认 `false`。
  - `rules.report_number_offset_from_voided`：XG 报告编号 = 作废报告编号尾号 + N，默认 1。
  - `rules.require_void_note` / `void_note_keyword`：变更报告需注明“原报告作废”。

**怎么用**

- 配置在 `p0/config/xg_report_number.yaml`，由 `p0/app/xg_rules.py` 读取；读取失败/缺文件回退默认关闭。
- 当前审核链路不调用该配置，不会产生任何 finding；等客户确认规则后再接 XG 模板与校验逻辑。

**已知局限**

- 规则语义（尾号是否含字母、原报告号从哪个字段取、作废声明放哪一页）未确认，配置项只是占位。
- 未做管理端配置入口与校验；改配置需改 YAML 并重启/重新加载。

## A9 · 目录页码一致（R18）

**检查什么**

- 目录条目的标注页码，与该标题在正文中首次出现所在页的页码比对。
- 正文页码取自页内「共 N 页 第 N 页」标记；一页合并多个打印页时按页内标记顺序归属；无标记时，若页脚页码与分页一一对应则按页脚页码。

**怎么判定**

- 可定位标题的目录页码 ≠ 正文页码 → `fail`（中），信息给标题、目录页码、正文页码，定位到正文实际页。
- 标题在正文找不到时不报 `fail`，只计入“未定位”；全部未定位、或无目录、或无法确定正文页码 → `skip`，不冒充 `pass`。
- 比对忽略空格与全半角冒号/括号差异；正文标题可带后缀（如「3.1来样方式：委托单位送样」）。

**已知局限**

- 纯 `PAGE` 域且无文本页码的文档无法定位正文页码（`skip`）。
- 一页内合并多个打印页码、且页码标记位于该页内容末尾时，归属可能偏差。
- 目录标题被解析器合并（如附录 E/F 挤在同一行）时该条未定位，不参与比对。
- 不检查目录条目顺序或越界（`R07` 已覆盖），也不判断标题文字本身是否规范。


## A10 · 错别字与病句（R21）

**检查什么**

- 内置错别字词典：常见误写（检侧/符和/气昧…）与两字词序颠倒（验检/告报/果结…），只收“倒过来不是词”的组合。
- 相邻重复：重复词（检验检验、通过通过）、重复的“的/了”、重复句读标点（，，。。；；：：、、）。
- 术语白名单：`检验检测` 内部含“验检”、`为了了解` 内部含“了了”、`目的的确` 内部含“的的”等规范写法先屏蔽再扫描，避免误报。

**怎么判定**

- 命中词典错别字 → `fail`（中）；仅命中重复字词/标点 → `warn`（低）。
- 每个受影响段落一条 finding，信息与定位栏均给 1-based 段落序号与原文片段；干净报告给 `pass`，无正文给 `skip`。
- 真实草稿 12 份回归：R21 12/12 `pass`（含 `检验检测专用章`、`主检主检批准批准审核审核` 签名标签行），0 误报。

**已知局限**

- 词典是内置高精度子集，不能覆盖任意错别字/病句；广义语义问题仍由 S01（DeepSeek，默认关闭）兜底。
- 段落序号是解析器收集的非空 `w:p` 序号，不是 Word 渲染页码；表格单元格段落也按此序号定位。
- 重复检测只看相邻连续文本，不处理跨 run/跨单元格拼接、间隔重复或语法层面的病句。
- 白名单是代码内常量，新增客户术语需改 `p0/app/typo_rules.py`；本次未接管理端配置。


## A11 · 检测依据标准年代号（R22）

**检查什么**

- 从「检验依据/检测依据」字段提取标准号：GB/GB/T、DB、行业标准（QC/T、JB/T 等）、Q/ 企业标准、T/ 团体标准，以及 ISO/IEC/ASTM 等国际标准。
- 标准号必须带具体年代号：4 位数字（1900–2099）；ASTM 允许官方 2 位年代号（`ASTM D638-14`），`e1` 版次后缀不影响判定。
- 标准号格式：国家标准/行业标准/国际标准前缀后应为数字；`GBT 1037-2021` 这类前缀后直接跟字母判为格式不合法；年代号位数不是 4 位判为格式不合法。

**怎么判定**

- 缺年代号、年代号位数/范围或前缀格式不合法 → `fail`（中），逐条列出标准号与问题；全部合法 → `pass`；字段为空或无标准号 → `skip`，不冒充 `pass`。
- 同一标准号重复出现只报一次；证据栏给出识别数、缺年代号数与格式不合法数，定位到「检验依据」。

**已知局限**

- 只检查检验依据字段（另有 `检验依据：…` 行与「检验依据」标题下一行的回退），不扫描正文其他位置引用的标准；企业标准 `Q/…` 组织代号若恰好以 4 位数字结尾，可能被当作年代号。
- 不校验标准名称/版本是否现行、不联机查新；未识别到标准号时只能 `skip`，不能证明报告写了标准。12 份真实草稿回归：R22 12/12 `pass`（`Q/BYDQ-A1901.404—2025`、`Q/BYDQ-A1901.1373—2018`），0 误报。


## A12 · 附录照片序号与试验前/中/后完整性（R23）

> **2026-11-08 第五版（保守化）**。前四版连续被验证拒绝，每次都是"实现符合定义，但定义在真实写法面前不够用"。
> 现在改为**只判能明确判断的形态，其余一律 `skip`**。原则：**宁可少报，不可错报**。

### 判定范围（只有这些才判）

**标准题注**：一行内**恰好出现一个** `照片N`（N 为阿拉伯数字），且能抽取到系列名或继承到上级标题。

```
外包装照片1            → 判（系列名=外包装）
照片2                  → 判（继承上级标题）
分项2照片3（外观）      → 判（系列名=分项2）
试验前照片1            → 判（阶段在前，属性）
照片1 试验前            → 判（阶段在后，属性）
外包装照片2，试验前完整外观检查，无破损。 → 判（题注可带说明，长度和句末「。」不影响）
外包装照片2，试验前可见划痕。           → 判（说明里的「可见」不影响）
外包装照片2，试验前检查结果如下。        → 判（说明里的「如下」不影响）
显示面板照片1           → 判（系列名=显示面板，含「显示」不影响）
```

正文叙述句不判（`随报告附照片2张。`、`试验过程中拍摄了照片1，…`、`照片1拍摄于试验前。`）：判断依据是 `照片N` 前后的叙述用词与「系列名是否短标签」，**不是整行长度**。长度超过 20 字且以「。」结尾的标准题注仍按题注判，不能当正文丢掉。

叙述用词只算**紧贴 `照片N`** 的：在 `照片N` 前紧邻，或在 `照片N`（含括号注）后紧邻。逗号后的说明（`…，试验前可见划痕。`、`…，结果如下。`、`…，详见正文。`）和系列名里含这些字（`显示面板照片1`、`记录仪照片1`、`说明书照片1`）仍按标准题注判；同一个词放在 `照片N` 前或后结论一致。

### 只判三种失败

| 情形 | 结论 | 消息 |
|---|---|---|
| `N < 1`（如 `照片0`） | `fail` | 序号从 0 开始，至少应从 1 开始 |
| 同组缺号 | `fail` | <系列名> 序号从 X 开始，缺 Y |
| 同组重复 | `fail` | <系列名> 序号重复 |

**同组** = 归一化后系列名相同（空系列名归到最近上级标题）。组内序号必须是 `1..N` 连续。

### 一律 `skip`（不报错，不算通过）

| 形态 | 为什么跳过 |
|---|---|
| **一行多个 `照片N`**（`外包装照片1、内包装照片1`、`照片1 试验前、照片2 试验中、照片3 试验后`） | 切分规则在真实文档里无法稳定成立；分三行又变成另一种结果——同语义不同结论，不如不判 |
| **列表型序号题注**（`1、2、3` 独立成行，无照片词） | 无法确认它是不是照片编号序列 |
| 序号不是纯数字（`照片一`、`照片A`） | 形态不支持 |
| 无法确定系列名与上级标题 | 分组不可靠 |
| `word/media` 无嵌入照片 | 没有可比对的图片 |
| 全篇没有任何阶段词 | 可能是别家格式，完整性判不了 |

**`skip` 必须在证据里写明原因**，不能静默跳过。

### 与前四版的差异（为什么砍）

| 前四版尝试 | 结果 | 现在 |
|---|---|---|

## A14 · 样品编号连续性与重复性（R24 / RA-5.4、RA-1.8）

## A15 · 结论页无判定时结果表不得判定（R25 / RA-1.6）

- **检查什么**：结论页「检验结论」的判定表述，与检验结果表「符合性判定」列是否出现“结论页无判定、结果表却有判定”的不一致。判定词覆盖 `符合/不符合`、`合格/不合格`、`通过/不通过`、`满足`；`符合性判定`、`合格证`、`通过率` 视为名词，不算判定表述；`/`、`—`、`不适用`、`未判定` 视为未判定。

## A16 · 原始记录版本有效性（R27 / RA-4.7）

## A20 · 公式变量与可执行规则（SP-6.2）

- **检查什么**：标准条款的 `式中：` 变量定义与显式等式（如 `变化率=（A-B）/B×100%`），转成可执行规则；`x=(x1+x2+...+xn)/n` 识别为均值模板。显式等式必须同时有 `式中` 变量定义，否则不抽取（避免把注记 `PRR=217Hz` 当公式）。只有类型词（算术平均）而没有等式时，按测量变量生成均值模板，不编造其他公式。
- **怎么判定**：先归一化全角符号与 `×÷%√²`，等式在**顶层** `，`/`；`/`。` 处截断（函数参数里的逗号不算边界，`max(a,b)` 保留完整），逗号结尾与句号结尾判定一致；再用 AST 白名单求值（不用 `eval`）。`注/备注/附注` 句子不抽取（`注记不是公式`）；`式中：` 变量定义只归属它前面的等式，后续句子不继承这些变量。规则状态为 `executable` / `missing_variables` / `not_executable` / `not_extracted`。表达式引用但 `式中` 未定义的变量进入 `missing_variables`（等式左侧目标变量除外），不补默认值；`x` 的定义覆盖 `x1/x2/xn` 系列。
- **判例表**（每条即 `p0/tests/test_formula_vars.py` 用例）：

| 输入 | 结果 | 理由 |
|---|---|---|
| `变化率=（A-B）/B×100%，A/B 均有定义` | `executable`，A=120/B=100 → 20.0 | 正例 |
| 只定义 A | `missing_variables=['B']` | 缺变量明确报出 |
| `x=(x1+x2+...+xn)/n，式中 x/n` | `mean(x)`，[1,2,3] → 2.0 | 省略号均值 |
| `x=max(a,b)，式中 a/b` | `executable`，a=3/b=4 → 4 | 多参数函数逗号不截断 |
| `PRR=217Hz，PD=577usec`（无 `式中`） | `[]` | 注记不是公式 |
| 同段公式带 `式中`、后接 `注：PRR=217Hz` | 只抽公式，`注` 不抽取 | 注记不是公式 |
| `注：PRR=217Hz` 在公式/式中之前 | 只抽公式 | 注记不是公式 |

- **已知局限**：只扫条款文本（`line_meta`），不解析表格/图片内公式；一个句子只取第一个等式；加权平均、标准差等复杂公式需显式等式；变量定义依赖 `式中：符号——定义` 形态；`%` 只作百分号单位处理；`missing_variables` 不含等式左侧目标变量。

## A21 · 数值合理性、单位一致性与小数位数（R26 / RA-2.4、RA-2.5）

- **检查什么**：检验结果表每一行的数值与「限值要求/判定要求/技术要求」的关系；判定要求、检验结果、单位列、结果/均值表头括号中的单位是否一致；同一「检验项目+样品编号」组（平行样）的检验结果小数位数是否一致。
- **怎么判定**：
  - 判定要求支持 `≤`/`不大于`/`不超过`、`≥`/`不小于`/`不低于`、`a~b`、`a-b`、`a±t`、`a以上/以下`；全角 `≤/≥/～/－` 与 `°C`/`µ` 先归一化为 ASCII/规范形式。
  - 数值超出上限/下限：该行判定为不符合/不合格/不通过/不满足时不报（报告已确认的真实不合格结果，判定正确性由 R06 负责）；判定为空、判定符合或没有判定列时报 `fail`。等于 `≤`/`≥` 边界算合规。
  - 单位：判定要求、结果单元格、单位列、结果/均值表头括号中的单位必须一致，不一致报 `fail`；只出现一侧、某一侧有多个单位，或单位不在 R16 白名单（如 `bar`）时不判，也不冒充通过。小数位：同一检验项目+样品编号组内 ≥2 个检验结果，小数位数不同报 `fail`；不同项目/样品不互相比较；组内只有 1 个值不判。
- **已知局限**：只判「检验结果表」（表头需含评价员/检验结果，与 R06/R20/R25 同一张表）；判定要求的单位取自报告本身，不联机读客户标准；未知单位不判；不判平行样数值偏离大小（本任务验收未要求，避免无阈值臆断）；判定要求没有比较符（如只写“3.3”）时不判数值范围。
