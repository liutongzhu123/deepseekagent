# 中汽零部件 AI 项目 · P1 开发准备（2026-11-02）

> 用途：P0 受控上线（11/14）之后，P1 生产化开发的范围、排期、人员、数据与接口前置条件。
> 口径：P1 = 把“可演示、可复核的 P0 业务链路”变成“多用户、可运维、可验收的生产系统”，不含全量 90 项需求。

## 1. P1 目标与非目标

**目标（Gate 2 后启动，4–5 个月，26–32 人月）**

1. 多用户、RBAC、项目/部门授权、SSO 预留、全量审计；
2. 业务数据从 JSON 文件迁到 PostgreSQL，原文件进 MinIO，具备版本、备份、恢复；
3. OCR/解析异步化，任务队列、进度、重试、并发控制；
4. CRM 价格/资质/排期、任务单、原始记录、样品系统按接口或 Excel 适配；
5. 三个工作台（报告审核、标准复核、报价）从 MVP 走向可日常使用；
6. 模型网关、多模型路由、超时/降级；WeKnora 权限、审计、MCP；
7. CI/CD、监控告警、日志、备份恢复、等保整改、渗透测试；
8. UAT、培训、运维手册、上线割接与回滚。

**非目标（保持 P2/全量交付）**

- 客服/小程序、全量 41 条报告规则、印章/签名/照片视觉、标准版本 diff、多租户完整计费；
- 全量 90 项需求的一次性交付；P1 只做生产化底座 + 已确认的业务优先级。

## 3. P1 工作分解（WBS）

### 3.1 身份、权限与审计（4–5 人月）

- 账号体系：本地账号 + 预留 OIDC/SSO；密码策略、锁定、重置；
- RBAC：管理员 / 复核人 / 销售 / 只读；按项目、部门、客户授权；
- 审计：登录、上传、复核、发布、报价、问答、导出全量留痕；留存期与导出；
- 数据行级权限：报告/标准/报价按项目隔离；
- 验收：权限矩阵用例、越权测试、审计查询。

### 3.2 数据层与文件存储（4–5 人月）

- PostgreSQL：报告、标准、条款、复核历史、报价、任务、审计、用户；
- JSONB 存解析结果，版本号与修订链；
- MinIO：原始 docx/pdf/xlsx、导出文件、报价表；预签名下载；
- 迁移脚本：现有 JSON/文件 → DB/对象存储；回滚脚本；
- 备份：每日全量 + WAL 归档；恢复演练（RPO ≤ 24h，RTO ≤ 4h）；
- 验收：迁移对账、恢复演练、版本回放。

### 3.3 异步任务与性能（4–5 人月）

- 任务队列（Redis/Celery 或等价）：OCR、标准解析、批量报告审核、Excel 生成；
- 进度查询、失败重试、取消、并发上限、超时；
- 大文件分片/断点；OCR 结果缓存；
- 性能目标：单份 44 页扫描件 ≤ 3 min；10 份并发不阻塞 API；P95 API ≤ 2s（不含异步任务）；
- 验收：压测报告、失败恢复、任务可观测。

### 3.4 业务集成（5–7 人月，依赖客户接口）

- CRM：价格库、项目名称映射、资质认可库、排期库；只读优先，写回后置；
- 任务单/原始记录/样品系统：导出文件适配 → API；
- 字段契约、对账规则、失败降级、人工兜底；
- 验收：2–3 个真实报价案例、接口对账 100%、异常路径演练。

### 3.5 应用与工作台（4–5 人月）

- 报告审核台：问题清单、证据定位、批量、导出、复核留痕；
- 标准复核台：条款编辑、复核清单、发布/回滚、版本 diff；
- 报价助手：模板管理、折扣/税率参数、审批前确认、CRM 导出；
- 知识问答：多轮、引用跳转、反馈、WeKnora 权限；
- 验收：三个工作台 UAT 脚本、键盘/空态/错误态。

### 3.6 模型与知识底座（3–4 人月）

- 模型网关：DeepSeek/本地模型路由、超时、重试、降级、成本计量；
- WeKnora：知识库权限、审计、MCP、发布/检索/引用口径统一；
- OCR：本地 RapidOCR 与云 OCR 的可切换策略；失败降级；
- 评测：20–30 条标准问答、报告规则金标准、解析准确率基线；
- 验收：评测报告、降级演练、成本看板。

### 3.7 运维、安全与交付（4–5 人月）

- CI/CD：测试、构建、镜像、灰度、回滚；
- 监控告警：服务、解析失败、模型调用、队列积压、磁盘/证书；
- 日志：结构化、脱敏、留存；
- 安全：传输/存储加密、上传校验、越权、依赖扫描、等保整改；
- 交付：UAT、培训、运维手册、割接方案、回滚演练。

## 8. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 客户接口缺失/数据质量差 | 集成变数据治理，工期拉长 | 尽调前置；Excel 适配兜底；分批上线 |
| 样本不足 | 指标不可外推 | Gate 1 前补金标准；标注样本量与置信区间 |
| 单机资源不足 | OCR/解析阻塞、稳定性差 | 扩容、异步队列、限流、降级 |
| 外部模型/网络不稳定 | 问答/摘要失败 | 本地模型优先、超时重试、降级与缓存 |
| 权限/审计返工 | 上线延期 | P1-S1 先做身份与审计，后续复用 |
| 范围蔓延 | 6 周 P0 被拉成全量 | 以本文件非目标清单为准，变更走 Gate |
