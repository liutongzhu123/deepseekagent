## 2. 样例与清单

样例来自客户本地材料，**不入库**；仓库只提供清单格式与脚本：

```bash
cp p0/scripts/uat_manifest.example.json /path/to/uat-manifest.json
# 填入本机绝对路径后运行
```

清单字段：

- `standards[]`：`path`、`project`；
- `reports[]`：docx 路径；
- `quotes[]`：`path`、可选 `template`（销售报价表模板）。

本机实际使用的样例清单与原始报告放在工单目录，不提交仓库。

## 3. 执行方式

服务需已登录/初始化，建议在本地 PostgreSQL + 对象存储 + `P0_TASKS_ENABLED=1` 下运行：

```bash
P0_UAT_PASSWORD='<admin password>' \
  .venv/bin/python scripts/uat_smoke.py \
    --base-url http://127.0.0.1:8140 \
    --manifest /path/to/uat-manifest.json \
    --report /path/to/uat-report.json \
    --markdown /path/to/uat-report.md --strict
```

脚本会：登录 → 上传标准（自动等待 202 任务）→ 详情/导出 → 首个标准复核留痕 →
发布（异步任务）→ 审核报告 → 生成报价并下载 CRM/销售表 → 空态/错误格式 →
创建 viewer 验证 403 → 审计查询；最后输出逐项结果和指标。
