# 报告交叉校验模拟资料演示

本演示用一组**完全虚构**的任务单、原始记录、样品和设备台账，运行现有 X01–X04 规则，供开发和接口联调使用。所有编号均以 `DEMO-` 开头，不来自客户资料。

## 运行

```bash
cd p0
python scripts/run_report_crosscheck_demo.py
```

预期四项均为 `PASS`：报告与任务单（X01）、报告与样品（X02）、报告与原始记录/检验日期（X03）、报告设备与台账状态/有效期（X04）。演示只读取 `demo/synthetic_report_inputs/` 下四份 CSV，不写文件、不联网。

## 覆盖边界

- 本演示确认规则接线和字段契约可用，不验证客户数据质量、客户实际字段口径或生产 API。
- 报告字段以 `ReportData` 模拟，不是客户报告原件的解析回归。
- 台账、记录和任务单各一条，仅覆盖四项规则的正常匹配路径；字段冲突、缺记录、过期设备等失败路径仍由 `tests/test_report_crosscheck.py` 覆盖。
- `RA_CONSIST` 等待状态继续保留，直到拿到获准使用的真实脱敏 D4 资料完成外部回归。
